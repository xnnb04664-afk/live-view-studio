A lightweight Windows webcam viewer and camera monitor: the controls you need for live preview and photo capture stay close at hand.

Open a live camera preview and switch input devices from the device settings.

Fit or fill, mirror the image, zoom from 0.5× to 4×, and pan freely.

LOCAL FIRST

Save locally first

Photos are saved on your PC first. Phone transfer is optional and off until configured.

CONTROL DOCK

Shape your controls

Choose dock buttons, position, and size. Collapse the dock or capture with a shortcut.

OPTIONAL AUDIO

Control each device

Select and toggle camera and microphone independently; use fullscreen and always-on-top too.

OPEN SOURCE

Inspect the code

Built with Electron, React, and TypeScript. MIT licensed and open to contributions.

LOCAL FIRST / OPT-IN TRANSFER

Your photos stay yours.

Preview and capture happen in the Windows desktop app, and photos are saved locally first. If you configure phone transfer, the app encrypts photos with AES-256-GCM before writing them to your own private GitHub repository. No personal repository token or personal service endpoint is built in. See the GitHub README for setup and least-privilege guidance.
