PHOTO / CONTROL

为取景而做，不多添一步。

一套轻量的 Windows webcam viewer 与 camera monitor 控制台：从实时预览到拍照，常用的画面控制都在手边。

LIVE PREVIEW

实时取景

启动摄像头后直接查看实时画面，并能在设备设置中切换输入源。

FIT / FILL

构图随手调

完整适应或填充裁剪、左右镜像、0.5×–4×缩放，以及自由平移画面。

LOCAL FIRST

先存本机

照片先保存到本地；手机通道是可选项，不配置时不会连接个人中转服务。

CONTROL DOCK

控制栏可调

自选按钮、位置和尺寸，也可收起控制栏或用快捷键拍照。

OPTIONAL AUDIO

设备各自控制

摄像头与麦克风分别选择、开关；还支持全屏和窗口置顶。

OPEN SOURCE

源码可读

基于 Electron、React 与 TypeScript，采用 MIT 许可，欢迎检查与贡献。

LOCAL FIRST / OPT-IN TRANSFER

照片由你掌控。

取景和拍照在 Windows 桌面应用中完成，照片先保存在本机。若你自行配置手机收图通道，应用会使用 AES-256-GCM 加密后再写入你自己的 GitHub 私有仓库；本项目没有内置个人仓库令牌或默认个人服务地址。安装、构建与最小权限配置请查看 GitHub README。
